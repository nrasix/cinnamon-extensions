# Cinnamon Extensions for Cinnamon 5.6

[English](README.md) | **Русский**

Репозиторий содержит адаптированные версии двух расширений для рабочего стола
**Cinnamon**, подготовленные для работы на **Cinnamon 5.6.x** — версии, которая
используется в Linux Mint 21.1 и других дистрибутивах с этим релизом Cinnamon.

Здесь лежат не оригинальные расширения, а их доработанные сборки: они сохраняют
функциональность оригиналов, но адаптированы под API и особенности Cinnamon 5.6.
Оригинальные версии и их авторы указаны ниже.

## Для кого этот репозиторий

- Для пользователей **Linux Mint 21.1** (и других систем с **Cinnamon 5.6**),
  которые не хотят или не могут обновить рабочий стол до более новой версии.
- Для тех, кому нужны **современный док** и **скругление углов окон** с
  настройкой границ и теней, но чья версия Cinnamon не поддерживается
  актуальными релизами расширений.
- Для тех, кто устанавливает расширения вручную или распространяет их через
  репозиторий spices.

> Если вы используете Cinnamon 5.8 и новее, скорее всего, лучше подойдут
> оригинальные версии расширений от их авторов.

## Расширения

### Mint-Dock

**Что это:** нативный и настраиваемый док для Cinnamon.

**Зачем нужен:** заменяет стандартную панель задач удобным доком в стиле
macOS/Plank и даёт широкие возможности персонализации:

- настраиваемый цвет и оформление фона;
- перестановка иконок и перетаскивание приложений из меню Cinnamon прямо в док;
- выбор положения дока (сверху, снизу, слева, справа, по центру, в начале или в конце);
- два режима скрытия: «умное» скрытие (Intellihide) и автоматическое;
- подсказки, разделители, корзина и другие настраиваемые элементы;
- индикатор уведомлений и полоса прогресса приложений;
- совместимость с X11 и Wayland.

**Кому подойдёт:** пользователям, которым стандартной панели Cinnamon
недостаточно и которые хотят получить настраиваемый док.

**Оригинальный автор:** [hilyxx](https://github.com/Hilyxx).

### Rounded Corners

**Что это:** расширение, которое скругляет углы окон и добавляет настраиваемые
границы и тени.

**Зачем нужен:** позволяет привести внешний вид окон к единому стилю и
настроить его под себя:

- скругление верхних и нижних углов окон приложений;
- собственные границы и тени для окон со скруглением;
- исключение отдельных приложений из скругления;
- отдельные настройки границ для разных приложений;
- разные границы и сила тени для активного и неактивных окон;
- режим, при котором граница скругления совпадает с естественной границей окна;
- поддержка окон Gtk3, libhandy, Gtk4, Adwaita и Qt.

**Кому подойдёт:** пользователям, которые хотят скруглить нижние углы окон,
увеличить радиус скругления темы, настроить границы и тени или сделать
внешний вид рабочего стола более аккуратным и единообразным.

**Оригинальный автор:** [klangman](https://github.com/klangman/CinnamonRoundedCorners).

## Установка

1. Скопируйте каталог расширения из `files/` в каталог расширений Cinnamon:

   ```bash
   mkdir -p ~/.local/share/cinnamon/extensions
   cp -r "mint-dock-5.6@hilyxx&nrasix/files/mint-dock@hilyxx" \
         ~/.local/share/cinnamon/extensions/
   cp -r "RoundedCorners-5.6@klangman&nrasix/files/RoundedCorners@klangman" \
         ~/.local/share/cinnamon/extensions/
   ```

2. Перезапустите Cinnamon (например, `Alt+F2`, введите `r` и нажмите `Enter`).
3. Откройте **Параметры системы → Расширения**, включите нужное расширение и
   настройте его через значок шестерёнки.
